# TL挂机助手

## 简介

TL挂机助手是网页游戏「天龙八部挂机版」（`jayczee.top` 的 tl、tl2、tl3 站点）的 Tampermonkey 托管脚本。它在游戏页面里加一个面板，按你勾选的策略自动处理日常、挂机、成长、装备、宝石、珍兽等操作；所有动作串行执行，受金币和经验预算约束。

本脚本建立在两位作者的工作之上：

- **[doai](https://greasyfork.org/users/1663189-doai)**：原作 [天龙八部挂机版 · 完整托管助手](https://greasyfork.org/scripts/604931)。本脚本以它的 0.1.5 版为基础，整体架构（策略、运行时、面板）以及日常、挂机、成长、装备回收、宝石、铁匠、裁缝、补药、预算、断线恢复等基础功能都来自原作。
- **[JimChan](https://greasyfork.org/users/1194127-jimchan)**：[完整托管助手（衍生版）](https://greasyfork.org/scripts/605228)（0.2.0，MIT 许可）。本脚本采用了它的四项功能：按缺口智能用药、额度填 0 表示不限、显示技能升级受阻原因、装备评分显示。

在此基础上，本脚本增加了实战评分、仓库、比武天梯、暗器、珍兽、逛摊排序等功能，详见[功能介绍](#功能介绍)。

有功能需求或 bug 反馈，请提 [issue](https://github.com/YatsukiRenka/tl-idle-helper/issues)，也可以在 [linux.do 的帖子](https://linux.do/t/topic/3152986/169)下回复。欢迎提交 PR。

## 如何使用

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。Chrome 和 Edge 还需要在扩展管理页打开“开发者模式”，否则 Tampermonkey 不能运行脚本。
2. 点击 **[安装 TL挂机助手](https://raw.githubusercontent.com/YatsukiRenka/tl-idle-helper/main/tl-autopilot.user.js)**。浏览器会打开 Tampermonkey 的安装页面，点“安装”。
3. 打开或刷新游戏页面，页面上会出现“TL挂机助手”按钮。点开面板，在各个标签页勾选需要的功能，点“保存策略”，再点“开始托管”。

更新：Tampermonkey 会自动安装新版本（默认每天检查一次），页面刷新后生效。脚本的“更新”页每天检查本仓库的最新版本；托管运行并开启“页面刷新后恢复托管”时，发现新版本会自动刷新页面。想立即更新，点“更新”页的“安装新版本”，或再点一次上面的安装链接。每个版本的更新内容见 [Releases](https://github.com/YatsukiRenka/tl-idle-helper/releases)。

注意：

- 不要和原作或衍生版同时启用，否则两个脚本会重复操作。在 Tampermonkey 里只保留一个。
- 配置保存在浏览器本地，重装或更新脚本不会丢失。
- 支持的游戏站点：`tl.jayczee.top:1212`、`tl2.jayczee.top:11212`、`tl3.jayczee.top:11212`。配置按站点分别保存，换站点后用日志页的“导出配置”和“载入JSON配置”搬过去。

## 功能介绍

功能按面板的标签页排列。每项功能都有独立开关。

### 挂机日常

- **挂机**：自动开始战斗，按角色等级选地图或固定地图；阵亡后返城重新选图，并限制每小时阵亡次数。
- **日常活动**：珍珑棋局、伪宋军领地、熊林，各自可设每日次数。
- **天灵丹**：每日到洛阳吴双处领取；挂机时没有双倍经验就自动使用一颗（优先用绑定的）。两项各有开关。
- **在线抽奖**：在线每 30 分钟得 1 次抽奖次数，每天最多 12 次。次数攒够一批（默认 12 次，可调）或当天次数已发完时，回苏州快活叁处一次抽完，再回挂机地图；没抽的次数跨天保留。奖品记入日志。背包需留 1 个空格；抽奖失败后 30 分钟内不再尝试。
- **比武天梯**（30 级开放）：每日点赞、领取名次奖励、自动挑战战力不超过自己一定倍数的对手。挑战和领奖需要回洛阳找比武校尉，点赞不中断挂机。每天 0 点（东八区）结算前的一段时间（默认 10 分钟，可调，填 0 关闭）回洛阳驻守并连续挑战：榜单每 30 秒刷新一次，不受每日挑战次数上限限制，期间不进副本。

### 成长装备

- **人物与技能**：自动升级人物和技能，可设目标等级和技能优先顺序；技能升不了时显示原因。
- **按评分自动穿戴**：背包和仓库里有更好的装备时自动换上。评分有两种：
  - 实战评分：按拟合的伤害公式，针对最近一张挂机地图上打过的怪物，计算“输出 × 生存”的变化。木桩和副本里的战斗不计入；还没有怪物数据时不换装，也不出售装备。
  - 固定权重：与游戏的基础评分相同。
- **评分显示**：
  - 逛摊淘宝的商品卡片、背包和仓库的装备图标上显示评分，可选实战评分或战斗力。
  - 装备详情里在战斗力下面显示实战评分，两行都用 △ / ▽ 标出相对当前穿戴是否提升。
  - 人物面板显示实战评分。
  - 逛摊淘宝可按战斗力、实战评分或实战提升百分比排序。
- **暗器养成**：自动洗炼属性和品质、领取暂存奖励、用人物经验喂养。

### 珍兽

- 没有出战珍兽时让最强的出战，自动领取珍兽掉落。
- 自动孵蛋并按资质筛选：资质均值达标的保留并上锁，其余放生；变异和二代珍兽不会被放生。
- 用人物经验喂养出战珍兽。

### 宝石工艺

- **宝石**：打孔、镶嵌、合成、雕琢、替换旧宝石，可设目标等级和最低成功率。
- **铁匠与神器**：鉴定、强化、神器冶炼、神节修复、神器打造。冶炼经验在挂机战斗中直接投入，不回城；可用经验攒够设定的数量（默认 500 万）才投一次，投入时全部投进去。
- **裁缝与御赐套装**：棉布和秘银装备打造、万灵石兑换套装。

### 出售补药

- **装备回收**：自动出售普通装备和指定材料，可保留套装、未到等级的装备和各部位最佳备用装。
- **自动存入仓库**：按品质存入，套装和双完美资质装备可单独设置。
- **补药与回复**：用金币补充药品，自动配置游戏内置的用药设置，按缺口选择药品。

### 预算设置

- 保留金币和经验的下限，每日金币、技能经验、冶炼经验的支出额度；额度填 0 表示不限。
- 刷新页面后恢复托管，断线后继续托管，长时间断线时自动刷新页面。
- 托管运行时防止标签页睡眠。

### 状态、更新、日志

- 状态页显示当前计划、最近动作和资源使用情况。
- 更新页每天检查本仓库的最新版本，显示更新内容并提醒；可一键打开 Tampermonkey 的安装页面，也可在发现新版本后自动刷新页面启用。
- 日志页可查看动作日志，导出或导入配置，导出诊断信息。
